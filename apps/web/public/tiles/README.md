# Local PMTiles

Placebuilt `dc.pmtiles` at `./dc.pmtiles`. It is intentionally **not checked in**:

- Run `scripts/build_pmtiles.sh` once that script exists, or fetch the artifact referenced in infra docs.

For offline UI development and CI browsers, Scout defaults to **`NEXT_PUBLIC_SCOUT_MAP_MODE=stub`** (see `BasemapView`).
