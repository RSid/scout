Planner status states — design mockup. One severity-aware StatusStrip is the single home for every planner state. It lives directly above the address inputs and is sticky to the top of the viewport while the planner is in view, so the message can't scroll out of reach (the bug in the current build, where the warning sits in the summary card up top).

Color is never the only signal: each variant pairs a distinct icon shape with a text label and the tint. Tokens drive every color (--color-warning-* for warnings, --color-danger-* for errors, neutral surfaces for info/pending), so this honors light/dark and propagates palette edits automatically. The message persists until the route settles — no manual Retry, per the agreed behavior.
